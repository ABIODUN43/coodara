# 1. Overview

The Codara database stores:

• Users

• Organizations

• Git repositories

• Repository analyses

• Architecture snapshots

• Architecture decisions

• Architecture memory

• Architecture evolution

• AI conversations

• Billing

• Audit logs

The database is designed for scalability and future migration from a Modular Monolith to Microservices.

# Conclusion

The Codara database is designed to support architecture analysis, architecture memory, architecture evolution, AI reasoning, and future enterprise collaboration. It emphasizes consistency, scalability, and extensibility while remaining simple enough for the initial Modular Monolith architecture. As Codara grows, additional tables and services can be introduced without requiring major redesigns to the core schema.
